# 战斗陀螺策略对战系统 — 设计文档

> 为 RIPTOP Arena 增加回合制策略对战层，将被动观察的碰撞模拟升级为主动博弈的策略战斗。

## 1. 概述

### 1.1 目标

在当前物理驱动的陀螺对战基础上，叠加一个**策略博弈层**：当两陀螺进入冲突区域时，弹出策略选择界面，玩家（和 AI）在 3 秒内选择行动，根据 4×4 行动矩阵结算结果，然后恢复物理模拟。目标是将操作性从"偶尔按冲刺"提升为"每轮都要读对手、做决策"的策略对战。

### 1.2 核心设计原则

- **分层不割裂** — 策略层叠加在物理层上，不替换物理层。策略胜出触发物理冲撞 + 额外伤害。
- **信息透明** — 双方能量值始终可见，倒计时清晰，结算结果有明确视觉反馈。
- **性格化的对手** — 三个敌人的 AI 行为差异明显，让玩家需要针对性调整策略。
- **节奏紧凑** — 3 秒决策窗口 + 3.5 秒冷却，保证每局 45 秒内有约 5-7 次策略回合。

## 2. 战斗循环

```
自由走位 ──→ 两陀螺距离 < 冲突半径 ──→ 策略冲突（慢放）──→ 结算冲击 ──→ 冷却 3.5s ──→ 自由走位
    ↑                                                                                           │
    └───────────────────────────── 循环直到一方倒下 ──────────────────────────────────────────────┘
```

### 2.1 自由走位阶段

- 陀螺在竞技场内自由旋转移动，物理模拟正常运行
- 玩家可用 WASD / 点击进行冲刺（现有系统保留）
- 能量值常驻 HUD 显示
- 此阶段持续到两陀螺距离低于冲突半径

### 2.2 策略冲突阶段

- **触发条件**：两陀螺距离 < 3.0 单位（冲突半径），且距上次冲突结束已过 3.5 秒冷却
- **时间行为**：3D 场景时间流速降至 20%（慢放），画面加暗角
- **操作窗口**：3 秒倒计时，超时未选择自动执行"防御"
- **操作方式**：
  - 桌面端：`1/2/3` 键选择进攻能量档位，`D` 防御，`S` 闪避，`C` 积蓄
  - 触屏端：底部横条四个按钮（进攻需额外点选能量档位 1/2/3）
- **双方选择隐藏**：玩家看不到 AI 的选择，AI 也看不到玩家的——这是同时博弈

### 2.3 结算阶段

- 时间恢复正常速度
- 根据 4×4 行动矩阵判定结果
- 进攻胜出 → 进攻方获得定向加速冲撞 + 能量伤害
- 防御/闪避成功 → 无碰撞或减伤
- 无事发生 → 双方继续物理模拟
- 触发对应的视觉特效（火花/闪电/震屏/战斗日志）

### 2.4 冷却阶段

- 3.5 秒内冲突区触发禁用
- 陀螺回到自由走位
- 玩家可以利用这段时间拉开距离或追击

## 3. 能量系统

| 参数 | 值 |
|------|-----|
| 起始能量 | 3 |
| 能量上限 | 10 |
| 积蓄行动收益 | +2 |
| 自然回复 | 无 |
| 防御消耗 | 对方进攻能量值 ÷ 2，向上取整 |
| 闪避消耗 | 0（免费） |

**设计意图**：能量是稀缺资源。积蓄需要专门行动，意味着放弃本轮的进攻/防御机会。每一点能量都需要规划使用。

## 4. 行动系统

### 4.1 四种行动

| 行动 | 快捷键 | 消耗 | 效果 |
|------|--------|------|------|
| ⚔️ 进攻 | `1` / `2` / `3` | 1 / 2 / 3 能量 | 对敌方造成伤害（详见结算矩阵） |
| 🛡️ 防御 | `D` | 对方进攻能量÷2↑ | 抵消对方进攻，物理碰撞减伤 40% |
| 💨 闪避 | `S` | 0 | 完全躲避偶数能量进攻（奇数无法躲避） |
| 🔋 积蓄 | `C` | 0 | 能量 +2 |

### 4.2 进攻档位

| 档位 | 按键 | 消耗 | 伤害 | 特性 |
|------|------|------|------|------|
| 轻击 | `1` | 1 | +3 integrity | **奇数 → 不可闪避** |
| 重击 | `2` | 2 | +6 integrity | 偶数 → 可被闪避 |
| 全力 | `3` | 3 | +10 integrity | **奇数 → 不可闪避** |

**策略深度**：1 档虽然伤害最低，但因为是奇数所以必定命中。2 档伤害中等但可被闪避。3 档伤害最高且必中，但能量消耗巨大。玩家需要根据对手习惯选择档位。

### 4.3 完整结算矩阵

| 玩家 ╲ AI | ⚔️ 进攻 | 🛡️ 防御 | 💨 闪避 | 🔋 积蓄 |
|-----------|---------|---------|---------|---------|
| ⚔️ 进攻 | 能量高者胜；相等则双方抵消，各自消耗投入能量 | 防御抵消进攻。防方消耗 ½攻方（↑），攻方消耗全额 | 奇数→必中；偶数→闪避成功。攻方消耗全额 | 进攻命中！蓄力方能量保留 |
| 🛡️ 防御 | 防御抵消进攻。防方消耗 ½攻方（↑），攻方消耗全额 | 无事发生，双方无消耗 | 无事发生，双方无消耗 | 蓄力方 +2 能量，防方无消耗 |
| 💨 闪避 | 奇数→必中；偶数→闪避成功。攻方消耗全额 | 无事发生，双方无消耗 | 无事发生，双方无消耗 | 蓄力方 +2 能量，闪方无消耗 |
| 🔋 积蓄 | 进攻命中！蓄力方能量保留 | 蓄力方 +2 能量，防方无消耗 | 蓄力方 +2 能量，闪方无消耗 | 双方各 +2 能量 |

## 5. 伤害系统（双轨结算）

策略回合胜出 → 两个效果同时发生：

### 5.1 物理轨 — 加速冲撞

进攻方陀螺向对手方向获得瞬时速度 boost：

| 进攻档位 | 推力 |
|---------|------|
| 轻击 | 3 单位 |
| 重击 | 6 单位 |
| 全力 | 10 单位 |

碰撞按原有物理规则计算 spin / integrity 伤害。推力大小同时影响飞出界（Ring Out）的概率。

### 5.2 策略轨 — 能量伤害

| 进攻档位 | 额外 integrity 伤害 |
|---------|-------------------|
| 轻击 | +3 |
| 重击 | +6 |
| 全力 | +10 |

### 5.3 防御/闪避效果

- **防御成功**：物理碰撞伤害 -40%，完全抵消能量伤害
- **闪避成功**：完全避开，无物理碰撞，无能量伤害
- **被命中**（包括进攻对撞失败方、积蓄被进攻方）：承受全额物理碰撞 + 能量伤害

## 6. AI 系统（性格驱动）

三个敌人有不同的行动倾向权重和动态调整逻辑。

### 6.1 Blaze Fang — 激进攻击型

```
进攻 55% / 防御 10% / 闪避 10% / 积蓄 25%
倾向档位：2~3
特性：上一回合进攻得手 → 下一回合进攻概率 +20%
      能量 < 3 时积蓄概率提升
```

### 6.2 Rift Drift — 狡猾闪避型

```
进攻 25% / 防御 15% / 闪避 40% / 积蓄 20%
倾向档位：1（利用奇数不可闪避的反制思维）
特性：若玩家上回合使用偶数档进攻 → 本回合闪避概率 +30%
      自身能量 > 6 时进攻概率提升
```

### 6.3 Atlas Guard — 稳守反击型

```
进攻 20% / 防御 40% / 闪避 15% / 积蓄 25%
倾向档位：2~3（积蓄后爆发）
特性：防御成功后的下一回合 → 进攻概率暴增至 70%
      能量 > 7 时必定选择进攻
```

## 7. UI 设计

### 7.1 策略冲突面板

- **位置**：画面中央偏下（桌面端）/ 底部横条（触屏端）
- **内容**：
  - 倒计时环（3 秒递减）
  - 玩家能量值 + 敌方能量值
  - 四个行动按钮（进攻含 1/2/3 能量档位子选项）
  - 当前回合结果预览区（结算后短暂显示）
- **视觉风格**：赛博朋克霓虹风格，与现有 UI 一致

### 7.2 HUD 常驻元素

- 能量条（0~10，在生命条旁边）
- 当前阶段指示器（自由/冲突/冷却）

### 7.3 快捷键映射（桌面端）

| 按键 | 行动 |
|------|------|
| `1` | ⚔️ 进攻 — 轻击（1 能量） |
| `2` | ⚔️ 进攻 — 重击（2 能量） |
| `3` | ⚔️ 进攻 — 全力（3 能量） |
| `D` | 🛡️ 防御 |
| `S` | 💨 闪避 |
| `C` | 🔋 积蓄 |

## 8. 视觉与音频反馈

| 事件 | 视觉 | 音频 |
|------|------|------|
| 冲突触发 | 时间慢放 + 暗角 + 面板弹出 | 低通滤波效果（声音变闷） |
| 进攻命中 | 加速冲撞 + 火花 + 震屏 | 碰撞音效（现有） |
| 防御成功 | 护盾闪光 + 能量波动 | 低沉嗡声 |
| 闪避成功 | 残影拖尾 + 风切效果 | 呼啸声 |
| 双方对攻 | 闪光爆发 + 震屏强度 ×1.5 | 爆炸音效（现有 burst） |
| 双方积蓄 | 双方能量条同时跳动 | 充电音效 |
| 倒计时最后 1 秒 | 红色闪烁 + 心跳脉冲 | 急促滴答声 |

## 9. 与现有系统的集成

### 9.1 保留的系统
- 竞技场 3D 场景和物理模拟
- 冲刺系统（WASD / 点击，在自由走位和冷却阶段可用）
- 零件/属性系统（attack/defense/stamina/mobility/burstResist 五维）
- 三种胜利条件（Ring Out / Spin Finish / Burst Finish）
- 回合时间限制（45 秒）
- HUD 生命条、战斗日志

### 9.2 修改的系统
- `game.ts` — 增加策略冲突阶段状态机，集成策略面板
- `battlePhysics.ts` — 增加加速冲撞接口，冲突区域检测
- `ai.ts` — 增加策略行动决策逻辑
- `rules.ts` — 结算逻辑扩展（无结构性变化）
- `hud.ts` — 增加能量条和冲突阶段 UI
- `combatLog.ts` — 增加策略行动日志

### 9.3 新增的系统
- `gameplay/clash.ts` — 策略冲突阶段管理（触发、窗口、结算）
- `gameplay/energy.ts` — 能量系统（增减、上限、消耗计算）
- `gameplay/clashAI.ts` — AI 决策系统（权重、动态调整、记忆）
- `ui/clashPanel.ts` — 策略冲突面板 UI（桌面端 + 触屏端）
- `fx/clashFeedback.ts` — 冲突相关的视觉反馈（暗角、慢放过渡等）

## 10. 三种游戏模式的适配

### 10.1 Quick Battle
策略系统完全启用。随机对手，一局定胜负。

### 10.2 Tournament Run
策略系统完全启用。三个敌人按 AI 性格依次挑战。

### 10.3 Survival Mode
策略系统完全启用。每波敌人随机性格（AI 随机从三种性格中选择权重模板）。精英敌人（每 3 波）获得 1.5 倍能量上限（15）。

## 11. 平衡性考量

- 初始 3 能量意味着第一轮冲突只能选择轻击（1）或非进攻行动——不会出现开场秒杀
- 防御消耗 = ½ 对方进攻能量（向上取整），即防御全力一击（3）消耗 2 能量——有代价但不至于太贵
- 闪避免费但只对偶数档有效——鼓励玩家混用奇偶档位
- 积蓄需要放弃一轮进攻——节奏控制的核心
- 3.5 秒冷却给了被击退方喘息空间，防止连续压制

## 12. 未包含的内容

以下功能明确不在当前设计范围内：

- 多人联机对战（需要服务器端权威结算）
- 能量相关的零件属性加成（后续可扩展）
- 策略行动的自定义快捷键配置
- 策略回放/复盘功能
