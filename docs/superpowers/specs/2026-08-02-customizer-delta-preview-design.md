# NSS 装配差值预览设计

日期：2026-08-02
状态：已批准，待实施

## 1. 背景与目标

Web Customizer 已支持五层零件选择、七属性附加、共鸣结算、撤销/重做和本地保存。本阶段在真正装备候选零件或属性之前提供临时差值预览，让玩家理解选择会带来的概念属性、属性数量、主属性和共鸣变化。

预览是只读界面状态，不改变当前组合或属性，不进入历史，不写入本地存储，也不触发 3D 模型加载。确认选择后继续使用现有零件和属性装配流程，竞技场战斗模式保持不变。

## 2. 成功标准

- 桌面鼠标、键盘以及手机触摸均有可用的候选预览入口。
- 零件预览显示六项概念属性中实际发生变化的项目。
- 属性预览显示实际变化的属性数量、主属性、共鸣类型和共鸣加成。
- 独立差值轨明确区分当前值与候选值，不临时覆盖正式属性面板。
- 预览离开或取消后恢复当前显示，不修改组合、属性、历史或加载状态。
- 短按、单击、Enter 和空格继续执行现有确认选择行为。
- 桌面和手机布局无覆盖、裁切或不可达内容。
- 专项单元测试、TypeScript、生产构建和 desktop/mobile E2E 全部通过。

## 3. 已批准的交互

### 3.1 桌面鼠标

- 鼠标进入未装备候选零件或未选择候选属性时立即开始预览。
- 鼠标移出该候选时结束预览。
- 单击仍直接确认选择，不增加二次确认。
- 当前已经装备的候选不显示差值轨。

### 3.2 键盘

- 候选按钮获得焦点时开始预览，失焦时结束预览。
- Enter 或空格继续触发原有按钮选择。
- 差值轨使用礼貌级动态播报，使辅助技术能够获知预览变化。
- 切换零件分类时清除旧分类的预览。

### 3.3 手机触摸

- 短按继续直接确认选择。
- 持续按压约 350ms 后进入预览；长按成功后的同一次触摸不得确认选择。
- 松手、`pointercancel`、`lostpointercapture`、页面失焦或页面变为隐藏时结束预览。
- 按压期间移动距离超过约 8 CSS 像素时取消长按计时，把手势交还给现有横向滚动。
- 长按不修改候选按钮尺寸，不阻止玩家滚动零件或属性横向列表。

## 4. 已批准的布局

采用独立紧凑差值轨。

- 零件差值轨位于零件候选横向列表之后、属性面板之前。
- 属性差值轨位于七属性选择条之后、正式共鸣摘要之前。
- 同一时间只显示一个差值轨；新的候选预览替换旧预览。
- 差值轨只显示发生变化的项目，不复制完整属性表。
- 上涨显示 `+`，下降显示 `−`，状态变化显示 `当前值 → 候选值`。
- 上涨、下降和规则变化同时使用符号、文字和颜色，颜色不是唯一信息。
- 手机端允许差值项目自然换行，差值轨保持在触发控件附近，不悬浮到 3D 视图上。

## 5. 差值内容

### 5.1 零件候选

构造只替换当前分类零件 ID 的临时 `Combination`，使用现有 `conceptAttributes` 分别计算当前值和候选值。

比较以下六项：

- 攻击
- 防御
- 持久
- 平衡
- 重量倾向
- 高度倾向

只显示非零差值。A2 属性附加在装配槽位上，因此单纯更换零件不改变该层属性，也不显示没有变化的属性数量或共鸣。

### 5.2 属性候选

构造只替换当前分类属性的临时 `AffinitySelection`，使用现有 `resolveAffinityProfile` 和 `createAffinityViewModel` 分别计算当前结果和候选结果。

显示以下实际变化：

- 七属性中数量发生变化的项目。
- 主属性变化。
- 共鸣类型或分布变化。
- 共鸣加成变化。

属性选择不改变零件组合，因此不显示六项概念属性的零差值。

### 5.3 无变化候选

候选与当前选择相同，或所有可展示结果均无变化时，比较模型返回 `null`，界面不显示空差值轨。

## 6. 组件边界

### 6.1 `comparisonModel.ts`

纯函数模块，提供零件比较和属性比较构造函数。输入当前数据和候选值，输出可展示的差值模型或 `null`。它只调用现有确定性计算函数，不读取 React 或 Zustand 状态。

### 6.2 `PreviewableButton.tsx`

复用现有按钮语义的交互组件，统一处理鼠标进入/离开、焦点/失焦、触摸计时、移动阈值和取消清理。它发送开始预览、结束预览和确认选择意图，不读取组合或属性规则。

长按成功后抑制同一次指针序列产生的点击。后续新的短按必须恢复正常选择，不能留下永久抑制状态。

### 6.3 `AffinityComparison.tsx`

纯展示组件，渲染标题、差值项目和状态变化。使用 `aria-live="polite"`，数值使用稳定宽度，避免差值变化造成布局跳动。

### 6.4 `App` 与 `AffinityPanel`

`App` 保存唯一临时预览描述，使用 `useMemo` 生成比较模型。零件选择列表接入预览按钮和零件差值轨。

`AffinityPanel` 接收属性预览开始、结束回调和可选差值轨，仍然只通过正式点击回调提交属性选择。它不复制属性规则。

不新增第二个 Zustand store，不把预览写入现有 store。

## 7. 数据流

1. 候选项收到悬停、焦点或成功长按。
2. 控件向 `App` 发送候选类型、分类和候选 ID/属性。
3. `App` 保存临时预览描述。
4. 纯比较函数构造候选组合或候选属性映射并计算差值。
5. `AffinityComparison` 渲染紧凑差值轨。
6. 离开、失焦、松手、取消、页面隐藏或切换分类时清空临时预览。
7. 只有正式选择事件才调用现有 `selectPart` 或 `setAffinity`。

## 8. 错误与边界处理

- 候选零件来自现有目录；若比较函数收到未知或分类不匹配的零件 ID，返回 `null`，不修改正式状态。
- 未知属性继续由现有类型与规则校验拒绝，比较 UI 不提供非法候选。
- 快速从一个候选移到另一个候选时，后一个候选替换前一个预览；旧候选的结束事件不得错误清除新的预览。
- 组件卸载时清除长按计时器，不在卸载后更新状态。
- 鼠标产生的模拟触摸事件不得启动第二套预览。
- 预览期间正式选择候选时，先清除预览，再执行现有选择动作。
- 页面隐藏或窗口失焦时统一清除预览，避免返回页面后保留过期比较。

## 9. 验证设计

### 9.1 纯函数单元测试

- 零件替换同时产生正、负和零差值，输出只保留非零项目。
- 相同零件返回 `null`。
- 属性替换只输出两个数量变化以及实际的主属性、共鸣和加成变化。
- 覆盖进攻共鸣获得、进攻共鸣失去、协调共鸣分布改变和主属性平票规则。
- 相同属性返回 `null`。
- 输入对象在比较前后保持不变。

### 9.2 交互组件单元测试

- 鼠标进入/离开和焦点/失焦正确开始、结束预览。
- 假计时器确认 349ms 不预览，350ms 开始预览。
- 超过移动阈值、`pointercancel`、`lostpointercapture`、页面隐藏和组件卸载均清理计时器与预览。
- 长按后的 click 被抑制一次，下一次短按恢复正常。

### 9.3 浏览器验证

- 桌面悬停候选零件显示六项差值中的变化项目，移出后消失。
- 键盘 Tab 聚焦显示预览，Enter 选择后差值轨消失并正常加载新模型。
- 属性候选焦点显示数量、主属性和共鸣变化，确认前 `load-status` 和历史深度不变。
- 手机短按仍直接选择；长按显示预览、松手恢复且不选择。
- 手机横向滑动超过阈值不会误触长按预览或选择。
- 桌面与手机截图确认差值轨无裁切、遮挡或布局跳动。
- 浏览器控制台无新增错误。

## 10. 非目标

- 不预览真实竞技场伤害、碰撞、速度或 AI 结果。
- 不修改概念属性计算公式。
- 不修改七属性、相克、共鸣或主属性规则。
- 不在预览期间加载候选 3D 模型。
- 不加入二次确认弹窗、比较收藏夹或多候选并排比较。
- 不改造与候选预览无关的定制器页面。

## 11. 实施顺序

1. 先编写纯比较函数和预览按钮的失败测试。
2. 实现比较模型与通用预览交互按钮。
3. 实现独立差值轨展示组件。
4. 接入零件候选和属性候选。
5. 增加响应式样式、无障碍状态和页面级清理。
6. 运行专项、完整回归、desktop/mobile E2E 和视觉验收。
