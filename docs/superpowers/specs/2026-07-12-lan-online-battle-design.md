# 局域网跨电脑真人对战设计

## 1. 目标

将现有本机双窗口 WebSocket 对战扩展为同一局域网内的两台电脑对战。主机电脑同时运行 Vite 前端和 Node.js 匹配服务器；另一台电脑只需使用浏览器访问主机局域网地址。

当前主机 WLAN IPv4 地址为 `192.168.1.42/24`。目标访问地址为：

```text
http://192.168.1.42:4176
```

## 2. 网络拓扑

- 主机电脑监听 HTTP `0.0.0.0:4176`。
- 主机电脑监听 WebSocket `0.0.0.0:8080`。
- 主机和对方电脑必须连接同一局域网，并允许设备之间直接通信。
- 两端都通过主机提供的网页进入游戏，点击“真人联机”后进入同一个匹配队列。
- Host/Guest 分配、房间、回合裁决和状态同步继续沿用现有 MVP，不改变物理或伤害模型。

## 3. 动态 WebSocket 地址

浏览器客户端保留 `VITE_WS_URL` 环境变量作为最高优先级覆盖。未配置时，不再写死 `ws://127.0.0.1:8080`，而是从当前页面 URL 派生 WebSocket 地址：

```text
http://127.0.0.1:4176       -> ws://127.0.0.1:8080
http://192.168.1.42:4176    -> ws://192.168.1.42:8080
https://example             -> wss://example:8080
```

实现使用标准 `URL` API 替换协议和端口，避免 IPv6 地址字符串拼接错误。
当前 Node 服务本身不终止 TLS；`wss://` 分支只为未来放到 TLS 反向代理后保留，当前局域网必须使用 HTTP/WS。

## 4. 跨设备开战时序

现有 `MATCH_START.startAt = Date.now() + 3000` 依赖两台设备系统时钟一致，不能用于局域网跨电脑。

协议改为发送 `startDelayMs`：

- Host 请求 `startDelayMs = 3000`。
- 服务器只接受 500 至 10000 毫秒的有限整数。
- 服务器向双方广播相同的相对延迟，并从收到请求时开始安排首回合。
- 每个客户端收到后使用本机单调时钟计算 `performance.now() + startDelayMs`。
- 局域网传输差异只会产生数毫秒级开场偏差，MVP 接受该误差。

服务器的 15 秒回合超时继续由服务器自身计时，不依赖客户端系统时钟。`TURN_OPEN.deadline` 仅用于显示和诊断，不参与客户端裁决。

## 5. 启动方式

在 `package.json` 增加：

```json
"dev:lan": "vite --host 0.0.0.0 --port 4176"
```

主机分别运行：

```powershell
npm run server
npm run dev:lan
```

启动日志应同时提示本机地址和局域网访问地址。另一台电脑访问 `http://192.168.1.42:4176`，无需安装项目或 Node.js。

## 6. Windows 防火墙

实现不自动修改系统防火墙。主机需要允许专用网络上的 TCP 入站端口：

- `4176`：Vite 页面
- `8080`：WebSocket 匹配服务

若 Windows 弹出网络访问提示，应只勾选“专用网络”。如果网络配置为公用网络、路由器启用了客户端隔离，或公司网络禁止设备互访，即使服务监听正确，对方电脑仍无法连接。

## 7. 安全边界

该功能仍是可信局域网 MVP：

- 不包含账号、TLS、鉴权或防作弊。
- 同一局域网中能够访问端口的设备都可以进入匹配队列。
- 不开放路由器端口映射，不建议暴露到公网。
- 公网阶段必须迁移到 HTTPS/WSS、加入身份验证并重新评估 Host 权威模型。

## 8. 验证计划

### 自动验证

- `npm run test:server` 继续通过。
- `npm run build` 继续通过。
- 使用 `http://127.0.0.1:4176` 时自动连接 `ws://127.0.0.1:8080`。
- 使用 `http://192.168.1.42:4176` 时自动连接 `ws://192.168.1.42:8080`。
- Node WebSocket 客户端可以通过 `ws://192.168.1.42:8080` 加入队列。
- `MATCH_START` 使用相对延迟，两端不读取对方系统时间。
- 本机双窗口匹配、Host/Guest 裁决、断线和超时回归通过。

### 跨电脑手动验收

1. 两台电脑连接同一 Wi-Fi 或有线局域网。
2. 主机启动两个服务并允许专用网络防火墙访问。
3. 对方电脑访问 `http://192.168.1.42:4176`。
4. 两端分别点击“真人联机”。
5. 确认自动匹配、统一倒计时和首回合开启。
6. 双方提交动作，确认 HP、Spirit、胜负和表现一致。
7. 关闭任一浏览器，确认另一端约 5 秒内返回菜单。

## 9. 成功标准

主机无需修改源码或 `.env`，另一台同局域网电脑只通过浏览器访问主机 IP，即可完成从匹配、自动开战、回合对抗到断线清理的完整真人对战流程；本机双窗口模式继续兼容。
