# 技能等级伤害与蓄力反击设计

## 1. 目标

让1至5级技能形成清晰、可感知的伤害阶梯。高等级技能必须对同级正常护甲目标造成更深伤害，同时保留装备攻击、暴击、蓄力反击和护甲养成价值。

参考战斗节奏：面对约 `2000 HP / 30 护甲 / 8 攻击` 的同级目标，1级技能约需 6–7 次击败，3级约需4次，5级约需2–3次。5级蓄力反击应造成接近致命的重创，但通常不能从满血直接击败目标。

## 2. 技能等级基础伤害

使用渐进加速曲线：

| 技能等级 | 基础伤害 | 灵力消耗 |
| --- | ---: | ---: |
| 1 | 400 | 20 |
| 2 | 580 | 40 |
| 3 | 800 | 60 |
| 4 | 1080 | 80 |
| 5 | 1400 | 100 |

等级基础伤害是回合技能伤害的主要来源。该表必须作为单一数据源，UI、伤害引擎和 QA 不能各自维护重复数值。

## 3. 伤害结算管线

### 3.1 面板伤害

```text
装备攻击加成 = 攻击值 × 25
技能面板伤害 = 技能等级基础伤害 + 装备攻击加成
```

装备攻击采用固定加算，不使用百分比放大。这样攻击装备可以稳定提升所有技能，但不会让高等级基础伤害再次指数增长。

### 3.2 战斗情境倍率

| 情境 | 倍率 |
| --- | ---: |
| 普通命中 | 1.00× |
| 高阶技能压制低阶技能 | 1.15× |
| 同阶拼刀震荡伤害 | 0.50× |
| 抓住蓄能空档的反击 | 1.75× |

当前高阶压制的 `1.50×` 调整为 `1.15×`，因为等级基础伤害已经体现强度差。当前蓄力反击调用中的 `0.65×` 衰减必须移除，避免抵消独立反击倍率。

### 3.3 暴击与反击

- 蓄力反击和普通暴击互斥。
- 反击固定使用 `1.75×`，不再进行普通暴击随机判定。
- 反击继续无视闪避。
- 普通非拼刀攻击继续按装备暴击率判定，并使用装备暴击倍率。
- 同阶拼刀不触发普通暴击。

结算伪公式：

```text
raw = skillBaseDamage[tier] + attack × 25

if counter:
  raw *= 1.75
else:
  raw *= contextMultiplier
  if normalCrit:
    raw *= critMultiplier
```

高阶压制和拼刀属于 `contextMultiplier`。蓄力反击拥有独立情境，不再叠加旧的 `0.65×` 或普通暴击倍率。

### 3.4 护甲

护甲常数从 `20` 调整为 `30`：

```text
护甲减伤率 = 护甲 / (护甲 + 30)
最终伤害 = max(1, round(raw × 30 / (30 + 护甲)))
```

常规 `20–35` 护甲将提供约 40%–54% 减伤。护甲保持递减收益，但不会像旧公式一样轻易压住技能等级差异。

## 4. 参考伤害

参考角色：`2000 HP / 30 护甲 / 8 攻击`。装备攻击加成为 `200`，护甲后保留 50% 伤害。

| 等级 | 普通命中 | 蓄力反击 | 高阶压制 |
| --- | ---: | ---: | ---: |
| 1 | 300 | 525 | 345 |
| 2 | 390 | 683 | 449 |
| 3 | 500 | 875 | 575 |
| 4 | 640 | 1120 | 736 |
| 5 | 800 | 1400 | 920 |

普通命中的参考击败次数约为 `6.7 / 5.1 / 4 / 3.1 / 2.5`。

## 5. 代码边界

### `src/types/battle.ts`

- 在技能配置或其相邻单一数据源中增加等级基础伤害。
- 保留现有 `tier` 和 `spiritCost`。

### `src/gameplay/damage.ts`

- `DamageContext` 增加 `skillTier` 与 `contextMultiplier`。
- 使用技能等级基础伤害和 `攻击值 × 25`。
- 实现反击与普通暴击互斥。
- 护甲常数改为 `30`。
- `DamageResult` 增加：
  - `skillTier`
  - `skillBaseDamage`
  - `attackBonus`
  - `contextMultiplier`
  - 现有 `armorReduced`

### `src/gameplay/battlePhysics.ts`

- 所有回合技能伤害调用显式传入对应技能等级。
- 高阶压制传入 `1.15`。
- 同阶拼刀传入 `0.50`。
- 蓄力反击不再传入 `0.65`。
- 不改写 `TurnArbitrator` 的招式奇偶、防守、回避或灵力流程。

### `src/app/game.ts`

- 根据 `DamageResult.skillTier` 缩放命中特效。
- 根据 `counter`、`crit` 和普通命中生成不同飘字。
- 联机 Guest 继续只消费 Host 返回的 `DamageResult`，不重新计算随机数。

## 6. 不包含的伤害

以下项目保持现状，不进入技能等级伤害公式：

- 普通物理碰撞伤害。
- 刃甲固定反伤 `350`。
- 火焰穿透固定伤害。
- 锁扣稳定度伤害。
- HP、护甲和装备属性生成公式。

## 7. 等级化打击反馈

```text
表现强度 = 1 + (技能等级 - 1) × 0.15
```

| 等级 | 表现强度 |
| --- | ---: |
| 1 | 1.00× |
| 2 | 1.15× |
| 3 | 1.30× |
| 4 | 1.45× |
| 5 | 1.60× |

表现强度只调整镜头震动、冲击波半径、火花数量、碰撞音效力度和飘字内容，不参与伤害公式。

飘字格式：

```text
普通：T5 -800
暴击：CRIT T5 -1520
反击：COUNTER T5 -1400
闪避：MISS
格挡：BLOCK
```

“绝对零度”场景继续使用现有粒子和 Bloom 限制。技能等级可以增强范围与震动，不能恢复过强的闪光亮度。

## 8. 验证计划

### 确定性数值验证

- 固定 `2000 HP / 30 护甲 / 8 攻击`，验证五级普通伤害为 `300/390/500/640/800`。
- 验证反击伤害为 `525/683/875/1120/1400`。
- 验证高阶压制使用 `1.15×`。
- 验证同阶拼刀使用 `0.50×`。
- 验证反击不会同时触发普通暴击。
- 验证普通暴击继续使用装备暴击率和倍率。
- 验证护甲递减收益、零护甲和极高护甲边界。
- 验证最终非闪避伤害至少为 `1`。

### 战斗流程验证

- 玩家、AI和联机 Host 使用同一套伤害引擎。
- Guest 应用 Host 的伤害结果，不重新随机。
- HP 在碰撞落点扣除，不在选择技能时提前变化。
- MISS、BLOCK、普通碰撞、刃甲和火焰穿透保持原行为。
- 连续多回合后双方 HP 与战斗结果一致。

### 视觉验证

- 使用 Playwright 分别触发1级和5级普通命中并截图。
- 检查5级震屏、冲击波、火花和飘字明显强于1级。
- 检查反击显示 `COUNTER`，普通暴击显示 `CRIT`。
- 检查经典、熔岩和绝对零度场景中陀螺仍清晰可见。
- `npm run build` 与现有服务器烟测必须继续通过。

## 9. 成功标准

技能等级成为回合伤害的第一决定因素，装备攻击提供稳定加成，反击和护甲形成清晰的战术修正。参考目标下，1级、3级和5级技能分别达到约 6–7、4和2–3次击败的节奏；5级蓄力反击造成约70%最大生命的重创，同时避免普通满血秒杀。
