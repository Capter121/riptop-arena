# 技能等级伤害实施计划

## 1. 建立单一等级伤害数据源

### 文件

- 修改 `src/types/battle.ts`

### 工作

1. 增加1至5级基础伤害常量 `400/580/800/1080/1400`。
2. 提供按等级读取基础伤害的类型安全函数。
3. 保持技能 `tier` 与灵力消耗配置不变。

## 2. 重写纯伤害计算管线

### 文件

- 修改 `src/gameplay/damage.ts`

### 工作

1. `DamageContext` 增加 `skillTier` 和 `contextMultiplier`。
2. 使用 `技能基础伤害 + 攻击 × 25`。
3. 实现反击 `1.75×` 与普通暴击互斥。
4. 护甲常数从 `20` 调整为 `30`。
5. `DamageResult` 输出等级、基础伤害、攻击加成和情境倍率。
6. 保留 MISS、BLOCK、锁扣伤害和最小伤害规则。

## 3. 接入回合裁决

### 文件

- 修改 `src/gameplay/battlePhysics.ts`

### 工作

1. 所有技能伤害调用传入对应 `tier`。
2. 高阶压制从 `1.50×` 调整为 `1.15×`。
3. 同阶拼刀保持 `0.50×`。
4. 蓄力反击移除旧 `0.65×`。
5. DIVINE 等现有专属情境保留原倍率，但仍使用新等级基础伤害。

## 4. 等级化打击反馈

### 文件

- 修改 `src/app/game.ts`

### 工作

1. 从 `DamageResult.skillTier` 计算 `1.00–1.60×` 表现强度。
2. 普通、暴击和反击分别显示 `Tn`、`CRIT Tn`、`COUNTER Tn`。
3. 按等级缩放冲击波、火花、震屏和碰撞音效。
4. 保留绝对零度场景现有亮度限制。
5. 联机 Guest 继续消费 Host 的完整 `DamageResult`，不重新随机。

## 5. 数值和流程验证

### 工作

1. 增加 QA 伤害矩阵入口，使用固定参考属性和固定随机值。
2. 验证普通伤害 `300/390/500/640/800`。
3. 验证反击 `525/683/875/1120/1400`。
4. 验证压制 `1.15×`、拼刀 `0.50×`、反击暴击互斥。
5. 验证零护甲、高护甲、MISS 和 BLOCK。
6. Playwright 对比1级与5级命中表现。
7. 运行 `npm run test:server`、`npm run build` 和 `git diff --check`。

## 完成定义

技能等级成为回合伤害主变量，参考数值矩阵精确通过，高阶技能在血条和表现上都明显更重，同时不改变普通物理碰撞、固定反伤、火焰穿透和网络权威边界。
