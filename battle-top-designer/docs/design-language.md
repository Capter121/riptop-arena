# 原创模块化战斗陀螺设计语言

## 1. 设计目标

建立一套可由 Blender 程序生成、可模块化组装、并与参考图片保持明显轮廓差异的原创设计语言。系统只继承抽象规律，不继承现有产品的识别性表达。

核心流程为：

```text
性能意图 → 形态语法 → 参数集合 → 模块组合 → 质量校验 → 原创性校验
```

性能意图不是结果保证。最终性能需要惯量、质心、碰撞和实物测试验证。

## 2. 原创形态语法

### 2.1 一级形态维度

每个设计必须独立确定以下维度：

1. **周向节奏**：接触区数量及长短关系。
2. **径向节奏**：局部外径峰值、谷值和过渡长度。
3. **接触语义**：Upper、Smash、圆滑卸力或向下防御。
4. **负空间**：窗口、凹口和层间开口的数量与相位。
5. **质量表达**：内重、外重、视觉偏心或真实偏心。
6. **材料分区**：透明材料、结构材料和金属的位置。
7. **层间相位**：各层分节是否对齐、交替或错位。

原创设计不得从单张参考图同时继承多个一级维度的具体组合。

### 2.2 主刃与辅助刃

主刃和辅助刃不通过现有产品式样定义，而通过参数关系定义：

- 主刃拥有更大的 `sector_span`、`radial_reach` 或 `contact_height`。
- 辅助刃用于补足周向节奏、过渡曲率或质量平衡。
- 主辅刃可以同层生成，也可以分处两个碰撞层级。
- 辅助刃不得只是主刃的等比例缩小；至少改变角宽、曲率或高度中的一项。

### 2.3 对称模式

- `rotational`：所有区等价，适合持久或稳定防守意图。
- `alternating`：A/B 交替，适合四刃、六刃或多刃混合语义。
- `phase_shifted`：不同层采用相同分节数但角度错位。
- `mass_corrected_asymmetric`：外观不对称，底盘配重使真实质心回到旋转轴。
- `true_eccentric`：真实偏心，仅允许作为实验参数，默认禁用。

## 3. 接触面规则

### 3.1 Upper 意图

- 使用沿旋向逐渐上升的接触高度。
- 前缘保持可制造的厚度，避免零厚度刀刃。
- 斜升面与后方结构连续连接，避免悬空尖片。
- 必须验证旋向、对手接触高度和结构强度。

### 3.2 Smash 意图

- 使用较短、接近径向的前缘和明确局部半径峰值。
- 只在少数主接触区使用，避免全周都是高应力尖峰。
- 为前缘提供圆角和后方支撑体积。
- 必须验证冲击应力和边缘安全性。

### 3.3 圆滑卸力

- 使用大半径连续圆弧和浅凹口。
- 控制相邻曲线的一阶连续，减少突变法线。
- 让外轮廓的峰谷差保持较小。
- 适合防守和持久意图，也可作为均衡型的部分接触区。

### 3.4 向下防御

- 接触区在视觉和剖面上包覆下层外缘。
- 下包边必须保留竞技场和对手零件所需间隙。
- 不允许未经验证的薄裙边或倒钩。
- 必须检查低姿态碰撞、刮地和爆裂风险。

## 4. 质量分布规则

### 4.1 内重心

- 将高密度体积集中在核心外侧的中半径区域。
- 外缘使用轻量接触骨架或较薄材料。
- 视觉上用向心肋和紧凑实体强化中心稳定感。

### 4.2 外重心

- 将高密度材料布置在连续外环或等距外侧配重舱。
- 配重舱必须周向质量匹配。
- 内层使用窗口或细肋减轻视觉和实际体积。

### 4.3 视觉偏心与质量校正

- 允许外观的刃长、负空间和颜色明度不对称。
- 在配重底盘内通过相反方向的体积补偿恢复质心。
- 建模后必须计算质心位置和主惯量轴；不能只凭视觉判断。

## 5. 材质层级

### 5.1 材质职责

| 材质层 | 主要职责 | 视觉规则 |
| --- | --- | --- |
| 透明/半透明覆层 | 深度、窗口、层间运动感 | 不承担未经验证的高冲击薄刃 |
| 结构塑料 | 连接、支撑、隔离 | 形成连续受力路径和清晰模块边界 |
| 金属接触/配重层 | 碰撞与质量表达 | 外露位置必须与结构职责一致 |
| 中心区域 | 装配焦点和状态识别 | 只用原创抽象几何或项目自有符号 |

### 5.2 配色原则

- 不从任何单张参考图提取完整主色、辅色、金属色组合。
- 先按功能定义明度层级，再独立选择项目色板。
- 同一系列可以共享材质规则，但四种类型不以固定商品式配色编码。
- 中心区域不得使用角色头像、动物徽章或近似现有 Logo 的图形。

## 6. 模块结构

以下均为**原创建议**，不是从参考图片反推出的现有接口。

### 6.1 三层版本

1. **接触冠层**
   - 定义外轮廓、接触面和主辅刃。
   - 可包含结构塑料与受控金属接触件。
2. **配重底盘**
   - 定义质量半径、周向配重和不对称补偿。
   - 不暴露参考产品式接口轮廓。
3. **核心驱动层**
   - 连接旋转轴、轴尖和轴向预紧结构。
   - 接口需要单独开展强度与误装防护设计。

### 6.2 四层版本

1. **视觉覆层**：透明或半透明，负责层次与识别。
2. **接触骨架**：负责主刃、辅助刃和碰撞载荷路径。
3. **配重底盘**：负责惯量和质心校正。
4. **核心驱动层**：负责轴向连接和旋转支撑。

四层版本的价值是把装饰、碰撞、配重和驱动职责分离；如果某层没有独立职责，应回退到三层，避免过度设计。

### 6.3 装配原则

- 接口几何必须从本项目需求独立设计，不能描摹参考图片。
- 同系列模块只共享一套必要接口，不提前设计多代兼容。
- 通过不可对称定位或清晰标记降低反装风险。
- 锁止强度、材料疲劳、儿童安全和高速爆裂风险均为待工程验证项。

## 7. 参数模型

### 7.1 核心参数

| 参数 | 含义 | 建议约束 |
| --- | --- | --- |
| `sector_count` | 接触区数量 | 整数，至少 2；上限由制造与性能验证确定 |
| `sector_phase` | 层或分节的角度偏移 | 归一化到一个分节周期 |
| `sector_span[]` | 各区角宽 | 总和需为凹口和过渡保留空间 |
| `radial_reach[]` | 各区径向伸出 | 不超过系统外径包络 |
| `leading_angle[]` | 进入边方向 | 与旋向和接触语义联动 |
| `trailing_curve[]` | 离开边曲率 | 保证曲线连续与最小圆角 |
| `notch_depth[]` | 区间凹口深度 | 受结构厚度和安全限制 |
| `contact_height[]` | 接触区高度 | 受层间干涉和竞技场间隙限制 |
| `downward_wrap[]` | 向下包边程度 | 默认低值，必须做剖面验证 |
| `mass_radius` | 主要质量半径 | 与性能意图和材料密度联动 |
| `mass_bias_angle` | 偏心或补偿方向 | 对称设计为无；偏序设计显式给出 |
| `symmetry_mode` | 对称方式 | 使用第 2.3 节枚举 |
| `material_zone[]` | 材料区域 | 不允许无结构依据的金属贴片 |
| `layer_count` | 三层或四层 | 仅允许 3 或 4 |

### 7.2 派生量

生成后计算：

- 外轮廓径向签名和峰谷数量。
- 最小壁厚、最小圆角和悬空区域。
- 几何质心、材料质心和主惯量轴。
- 周向质量方差。
- 层间干涉、装配方向和外径包络。

### 7.3 参数化禁区

- 不录入参考图片的精确轮廓控制点。
- 不把现有接口尺寸或卡扣截面作为参数预设。
- 不提供参考产品配色预设、徽章或名称库。
- 不以“随机扰动现有轮廓”作为原创生成方法。

## 8. 四套原创设计方向

### 8.1 攻击型 A-01「断续彗环」

**轮廓**：五个非等宽接触区，由“短直切面—内收缺口—长弧离开面”构成。两个主区较宽，三个辅助区较短，通过底盘质量补偿保持平衡。

**接触语言**：主区使用斜升面表达 Upper 意图，局部短直前缘表达 Smash 意图。

**质量语言**：两个主区配置外侧质量，反方向设置隐藏补偿，不使用真实偏心作为默认方案。

**明显差异**：采用五区断续节奏、长短混合刃和非连续旋涡；避开参考中高频的三角三刃、三个同形翼和四钩连续旋涡。

**待验证**：质心、主刃冲击应力、斜升面真实接触高度。

### 8.2 防守型 D-01「七湾缓冲环」

**轮廓**：七段浅凹湾组成近圆外缘，各段以宽圆角连接；内部三个透明拱桥与外部七分节错位。

**接触语言**：连续圆弧负责卸力，低幅向下包边表达防御意图。

**质量语言**：连续金属环厚度缓慢变化，不形成离散大尖峰。

**明显差异**：采用七段低振幅波形与 7:3 内外错位；避开三盾、四盾、大型兽爪和等角三角护甲构图。

**待验证**：下包边间隙、连续环受力和碰撞后的爆裂风险。

### 8.3 持久型 S-01「九脉静环」

**轮廓**：接近圆形的连续外缘，仅保留九个低幅微凸；九条细径向肋与外缘微凸错开半个节距。

**接触语言**：大半径圆角和低峰谷差，微凸只表达转速节奏，不作为主攻击刃。

**质量语言**：外缘连续窄金属环，内层以透明窗口和细肋减轻体积。

**明显差异**：采用九重微节奏和半节距错位；避开三刃骨架、长翼旋涡、蛇尾式曲线和高频尖齿复制。

**待验证**：外环惯量、周向质量一致性和细肋强度。

### 8.4 均衡型 B-01「双相偏序盘」

**轮廓**：两个长弧主区加三个短弧副区，形成 `2+3` 的五区偏序。透明层使用偏置椭圆负空间，金属底盘围绕真实旋转轴校正。

**接触语言**：一个长弧表达斜升意图，另一个表达圆滑卸力；三个短区分别承担过渡、低幅包边和质量补偿。

**质量语言**：视觉偏心、质量平衡；真实偏心默认禁用。

**明显差异**：采用 `2+3` 非等距节奏、偏置椭圆负空间和混合接触面；不把现有攻击轮廓与防守轮廓直接拼接。

**待验证**：隐藏补偿质量、混合接触面相互干涉和动态稳定性。

## 9. 生成与验证流程

1. 选择性能意图和层数。
2. 选择原创周向节奏，不从参考图提取控制点。
3. 生成二维径向签名和负空间。
4. 分配接触语义与层高。
5. 生成配重底盘并计算质心、惯量轴。
6. 检查壁厚、圆角、干涉和外径包络。
7. 执行 `originality-checklist.md`。
8. 通过后才允许进入精细建模和材质阶段。

任何步骤失败都应修改参数源，而不是在最终网格上做无法追溯的局部修补。
