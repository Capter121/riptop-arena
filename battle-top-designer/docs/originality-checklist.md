# 战斗陀螺原创性检查清单

## 1. 使用范围

本清单用于参考研究、参数定义、建模和导出阶段的内部原创性控制。它不能替代商标检索、外观设计专利检索、自由实施分析或专业法律意见。

检查对象包括名称、图形、轮廓、机械接口、材料分区、配色组合和整体视觉印象。

## 2. 绝对禁止项

任一项为“是”时，设计不得继续：

- [ ] 是否使用或近似使用参考产品名称、系列名或角色名？
- [ ] 是否包含现有商标、Logo 或足以使人联想到其来源的变体？
- [ ] 中央区域是否复制角色头像、动物徽章或参考图案构图？
- [ ] 是否描摹、扫描或矢量追踪了某张参考图片的外轮廓？
- [ ] 是否复制现有机械接口的精确截面、齿数、卡扣位置或尺寸？
- [ ] 是否直接复用了某张参考图片的整套主色、辅色、透明色和金属色组合？
- [ ] 是否把现有产品模型稍作缩放、旋转、镜像或随机扰动后称为原创？
- [ ] 是否把参考图片、徽章贴图或其裁剪内容打包进模型？

## 3. 证据使用检查

- [ ] 每项参考结论是否标明为“观察”或“推导”？
- [ ] 图片无法显示的底部结构是否没有被写成观察事实？
- [ ] 三层/四层接口是否明确标注为原创建议？
- [ ] 性能描述是否使用“意图”“倾向”或“待验证”，而不是无依据的保证？
- [ ] 跨分类重复图片是否只计一次视觉证据？
- [ ] 是否避免在原创设计命名中沿用参考文件名？

## 4. 轮廓原创性检查

### 4.1 一级形态维度

将候选设计与最接近的单张参考图比较。至少重新设计以下维度中的三个，并且不得只做微小数值调整：

- [ ] 接触区数量或主辅关系。
- [ ] 外轮廓峰谷的周向位置。
- [ ] 主刃角宽及长短节奏。
- [ ] 进入边方向和离开边曲率。
- [ ] 凹口深度与负空间拓扑。
- [ ] 层间相位和分节对齐方式。
- [ ] 可见质量块的位置和连续性。
- [ ] 材料区域边界。

“改变三个维度”只是内部最低门槛，不表示法律意义上的充分差异。如果整体印象仍然接近，必须继续重设计。

### 4.2 轮廓叠影

- [ ] 是否把候选轮廓与全部参考轮廓统一中心、外径和旋向后进行叠影？
- [ ] 是否检查主峰数量、主峰角位置和最大凹口位置？
- [ ] 是否存在长距离轮廓重合，而不仅是不可避免的圆弧重合？
- [ ] 镜像或反转旋向后是否仍与某张参考高度接近？
- [ ] 缩略图状态下是否会被误认成某个参考产品？

若出现明显长距离重合，应回到参数源修改 `sector_count`、`sector_span`、`sector_phase`、`radial_reach` 或负空间拓扑，不能只增加表面刻线掩盖相似性。

### 4.3 四套方向的专用差异门槛

#### A-01「断续彗环」

- [ ] 是否保持五个非等宽接触区，而没有退化为三刃或四钩旋涡？
- [ ] 两主三辅是否在角宽、曲率和高度中至少两项不同？
- [ ] 是否没有使用角色式中心徽章补充识别？

#### D-01「七湾缓冲环」

- [ ] 是否保持七段低幅波形和 7:3 内外错位？
- [ ] 是否避免三盾、四盾、大爪或等角三角护甲构图？
- [ ] 外缘是否以连续圆角为主，而非隐藏的攻击尖峰？

#### S-01「九脉静环」

- [ ] 是否保持九个低幅微凸和半节距错位？
- [ ] 是否避免三个长翼、蛇尾旋涡或高幅尖齿？
- [ ] 外侧质量视觉是否周向均匀？

#### B-01「双相偏序盘」

- [ ] 是否保持 `2+3` 偏序，而不是常规等距三刃或四刃？
- [ ] 偏置椭圆负空间是否为原创拓扑？
- [ ] 是否通过原创底盘质量校正，而不是复制某个现有配重位置？

## 5. 接触面检查

- [ ] Upper 意图是否通过原创高度曲线形成，而不是复制参考刃面？
- [ ] Smash 前缘是否有足够圆角和支撑体积？
- [ ] 圆滑卸力区是否保持曲率连续，没有装饰性尖峰破坏功能？
- [ ] 向下包边是否为原创剖面，并检查离地与层间间隙？
- [ ] 主刃、辅助刃和非接触装饰是否职责清楚？
- [ ] 所有性能说法是否标为待仿真或待实测？

## 6. 质量分布检查

- [ ] 内重、外重或偏心意图是否有明确的材料体积分配支持？
- [ ] 视觉偏心设计是否计算了材料质心？
- [ ] 质心是否位于允许的旋转轴偏差内？该容差需由后续工程规范定义。
- [ ] 主惯量轴是否与旋转轴满足后续工程规范？
- [ ] 周向配重是否存在未经说明的质量差？
- [ ] 真实偏心是否默认关闭并作为实验项隔离？

## 7. 模块与接口检查

- [ ] 接口是否从本项目功能需求独立设计？
- [ ] 是否保存接口推导草图和设计理由，而不是只保存最终形状？
- [ ] 是否避免使用参考产品相同的齿数、卡扣角位置和锁止轮廓组合？
- [ ] 三层结构中每层是否分别承担接触、配重或驱动职责？
- [ ] 四层结构中的视觉覆层是否确有独立职责？若没有，是否回退三层？
- [ ] 是否具有防反装或清晰定位策略？
- [ ] 是否检查装配干涉、轴向预紧和高速爆裂风险？
- [ ] 接口强度和疲劳寿命是否标为待工程验证？

## 8. 材质、图案与配色检查

- [ ] 透明材料、结构塑料和金属是否按功能分层？
- [ ] 是否没有从单张参考图提取完整配色方案？
- [ ] 是否先定义明度和材质职责，再选择项目自有色板？
- [ ] 中心区域是否只使用抽象几何、材料纹理或项目自有符号？
- [ ] 中心符号是否经过反向图片和商标近似检查？
- [ ] 表面刻线是否服务结构或原创节奏，而不是模仿参考装饰？
- [ ] 导出文件是否不包含任何参考图片或参考文件名？

## 9. 分阶段闸门

### 9.1 建模前

- [ ] 已记录性能意图和不保证的性能项。
- [ ] 已确定原创周向节奏、负空间和层间相位。
- [ ] 已选定三层或四层，并说明每层职责。
- [ ] 已选出最接近的参考样本用于主动避让。
- [ ] 已完成一级形态维度差异检查。

### 9.2 建模中

- [ ] 参数源可追溯，没有导入或描摹参考轮廓。
- [ ] 已生成轮廓径向签名并执行叠影检查。
- [ ] 已计算几何质心和材料质心。
- [ ] 已检查最小壁厚、最小圆角、悬空薄片和层间干涉。
- [ ] 修改发生在参数层，而不是用不可追溯的网格修补掩盖相似性。

### 9.3 导出前

- [ ] 名称、对象层级、材质名和贴图名均为项目原创命名。
- [ ] 没有参考图片、Logo、角色图案或来源水印进入文件。
- [ ] 缩略图、俯视图、侧视图和轮廓图均通过原创性复核。
- [ ] 最接近参考样本及差异理由已记录。
- [ ] 待工程验证项没有被标记为已验证。
- [ ] 审核者和日期已记录。

## 11. 失败处理

如果候选设计未通过原创性检查：

1. 保留失败记录，标明相似来源和问题维度。
2. 回到形态参数层修改周向节奏、峰谷位置、负空间或层间相位。
3. 不以添加刻线、换色、镜像或轻微缩放作为主要修正。
4. 重新执行轮廓、接口、中心图案和配色检查。
5. 通过复审前不得进入最终材质、导出或生产阶段。
